# Happy-Herbivore
Dit project is een web-based bestelsysteem voor een restaurant.
Gebruikers kunnen producten selecteren, een bestelling plaatsen
en een bon laten printen met een pickup-nummer.

## Functionaliteiten

- Producten bekijken per categorie
- Winkelmand toevoegen/verwijderen
- Bestelling plaatsen via API
- Automatisch pickup-nummer genereren
- Bon printen via USB printer
- Bedankpagina met bestelnummer

## Technologieën

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- WebUSB API
- phpMyAdmin

## Installatie

1. Clone de repository
2. Plaats de bestanden in de htdocs map
3. Import de database via phpMyAdmin
4. Pas database gegevens aan in config.php
5. Start een lokale server (bijvoorbeeld XAMPP)

## Database

Belangrijke tabellen:

- products
- categories
- orders
- order_items
